Stock Trading Platform

This is a simple Java console application made for CodeAlpha Task 2.

The program simulates a small stock trading system where a user can check stock prices, buy and sell shares, and keep track of their portfolio.

Features

- View available stocks
- Buy stocks
- Sell stocks
- Check portfolio
- View transaction history
- Update stock prices
- Track available balance

Stocks Included

- TCS
- INFY
- RELIANCE
- HDFC
- ITC

The prices used in this project are only for simulation and are not real-time stock prices.

How to Run

Open the terminal in the project folder and run:

javac Main.java
java Main

Menu

1. View Stocks
2. Buy Stock
3. Sell Stock
4. View Portfolio
5. Transaction History
6. Update Market Prices
7. Exit
